git checkout feature-name Switches to the selected branch so the teammate can work on their feature. git add . Stages the changed files so they are ready to be committed. git commit -m "Add login page" Saves the changes in Git history with a meaningful message. git push origin feature-name Uploads the feature branch to the remote repository so other teammates can review it. git pull origin main Gets the latest changes from the main branch and helps the teammate keep their branch updated. Workflow Create branch → Write code → Test → Commit → Push → Pull Request → Code Review → Merge into main This workflow ensures that only reviewed and tested code is merged into the main branch, reducing the risk of breaking the website before the client demo.
