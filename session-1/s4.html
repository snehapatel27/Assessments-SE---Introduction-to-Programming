Bootstrap's Grid System uses a 12-column layout to create responsive designs. We can control how many columns an element occupies at different screen sizes using Bootstrap's grid classes, without writing custom media queries.

Class Meaning What it controls col-12 12 columns On extra-small screens, the article takes the full row, so 1 article per row. col-md-4 4 columns from medium screens and above On medium, large, and extra-large screens, the article takes 4 out of 12 columns, so 3 articles per row. How It Works Mobile screen: col-12 → 12 columns → 1 article per row Desktop screen: col-md-4 → 4 columns each → 12 ÷ 4 = 3 articles per row Example with Three Articles
